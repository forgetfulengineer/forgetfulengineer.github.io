【AI】agent skills 安裝、管理、應用

2026-11-12-回覆文章分享

本篇重點

  • AI Agent Skill 的標準目錄結構
  • 透過 Vercel Skills CLI 與 skills.sh 進行社群 Skills 的搜尋、安裝及生命週期維護流程
  • 簡介 Netlify Agent Skills 實務案例

AI Agent Skills 是什麼

AI Agent Skills 是可重複使用的任務指引，讓 Agent 在特定任務（例如：審查程式碼、操作某個框架）時依指引做法執行。

通常包含 SKILL.md （YAML frontmatter，name、description），並可附帶 scripts/、references/、assets/，Agent 會根據 Skill 的名稱、描述與當前任務判斷是否需要載入相關指引。

範例

網站開發工作可以使用不同的 Skills：

  • 前端開發：遵循元件設計、無障礙及程式碼規範。
  • Netlify 設定：查詢建置指令、重新導向及部署環境的設定規則。
  • 程式碼審查：依照指定檢查清單尋找潛在問題。

健忘筆記

Skill 不一定會直接執行程式或呼叫外部服務，它也可能只是提供正確的操作知識，讓 Agent 根據專案情境完成工作。

使用 Vercel Skills CLI

Vercel Skills CLI 可以透過 npx 執行，不必先全域安裝套件。

Skills CLI 需要 Node.js 22.20 或更新版本

搜尋 Skills

可以在 skills.sh 瀏覽 Skills，確認來源 Repository、用途及安裝方式；也可以直接透過 CLI 搜尋。

安裝指定 Skill

透過 CLI 安裝 skill，以下使用 Netlify 官方 skill 做示範

若需要指定目標 Agent，可以透過 -a 或 --agent 選項；全域安裝則可使用 -g。

Skills CLI 支援多種 agent 安裝，詳細支援項目可查看 Supported agents

更新與移除

CLI 有對應命令，不需手動處理、調整

健忘筆記

npx skills update 無法透過 -a 指定 Agent，執行時會更新 Universal 與 Claude Code，並在專案中建立 .claude/ 內容。若僅需更新特定 Agent，改用 add 搭配 -a 重新安裝 npx skills add <原始來源> --skill <指定 skill> -a <指定 agent>

skills-lock.json

使用 npx skills add 安裝專案層級的 Skill 後，專案根目錄會出現 skills-lock.json。此檔案記錄已安裝 Skills 的來源與內容雜湊，用於重現安裝結果與偵測內容變動。

skills-lock.json 屬於專案安裝資訊，建議納入 Git 版本控制，讓團隊成員能夠了解專案使用哪些 Skills 及其來源。CLI 也提供實驗性指令 experimental_install，可依照 Lock File 還原已記錄的 Skills：

Netlify Skills 實作案例

Netlify 官方 Repository netlify/context-and-tools 提供多個針對平台功能的 Skills，例如：

Skill用途
netlify-confignetlify.toml、建置設定、重新導向、HTTP 標頭及部署環境
netlify-functionsServerless Functions 的開發與設定
netlify-blobsBlob 儲存功能

讓 Agent 依照 Netlify 平台的實際規則處理開發工作，而不是只根據一般網站開發經驗推測設定方式。

安裝 Skill

另提供全部安裝且互動模式回答都為 “yes” 的指令 npx skills add netlify/context-and-tools --skill '*' --yes。只用到少數 Skill 的時候，可以依照需求加上 --skill <指定skill> 安裝，這樣能減少載入的內容。

netlify-config 的原始內容位於官方 Repository 的 skills/netlify-config/SKILL.md，這份 Skill 著重於 Netlify 設定規則，包括建置設定、重新導向、標頭與部署環境等項目。

使用 Skill

假設專案使用 Vite，並透過 Netlify 部署，可以載入 netlify-config skill，並詢問 AI agent 建置指令與套件管理工具是否一致、發布目錄設定是否錯誤，以及重新導向規則是否不符合預期…等等。

驗證安裝

健忘筆記

netlify 也有自己的一套 CLI 可以針對安裝、更新、檢查 skill 的狀態，詳細可查看官方說明

常用指令

操作指令或方式注意事項
搜尋 Skillnpx skills find搜尋結果仍需確認來源
安裝指定 Skillnpx skills add <repo> --skill <指定skill> -a <agent>確認目標 Agent 與安裝範圍
驗證安裝npx skills list、ls .agents/skills/重啟 Agent 後確認可辨識
更新npx skills update <指定skill>既有安裝設定更新
移除npx skills remove <指定skill>避免使用 --all

結論

AI Agent Skills 的核心是 SKILL.md，將特定任務的知識與操作規範封裝成可重複使用的套件，適合用來補充網站開發、設定檢查及程式碼審查等工作所需的專業資訊。

Vercel Skills CLI 提供通用的搜尋、安裝、更新及移除流程，實際使用時，Skill 的安裝成功與否、Agent 是否辨識，以及操作結果是否正確，需個別做驗證、測試。Skills 提供的知識也不等於外部服務的操作權限，涉及正式環境與機密資訊時，應該保留必要的人工審查！
