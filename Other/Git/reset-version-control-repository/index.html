【Git】如何重置版本控制專案

2026-10-20-回覆文章分享

本篇重點

  • 移除專案根目錄的 .git，即可移除本機既有 Git Repository，並且不影響其他專案檔案
  • .git 移除後，原本的 commit history、branch、tag、remote 與 Repository 層級設定等都不再存在
  • 重新初始化 git 版控流程

先了解這些會幫助你更快理解唷😁

【Git】了解 git config 設定

在軟體開發過程中，若遇到專案架構大幅改動、歷史紀錄過於混亂或是要將既有專案作為新模板發佈時，可以考慮徹底清除舊有 Git 歷史紀錄並重新初始化。

Git Repository 的本機資料位於專案根目錄的 .git，其中包含 Repository 的物件資料、references、Repository 層級設定等。git init 建立新的 Repository 時，同樣會建立新的 .git 目錄。

移除本機 Git 版控

移除專案版控的機制在於刪除專案根目錄下的 .git 隱藏資料夾。

  • 保留範圍：工作目錄中的所有實體程式碼、資源檔案與資料夾結構不受影響。
